# 💫 About Me:
I focus on red teaming Active Directory and cloud environments, integrating AI to enhance reconnaissance, alerting, and attack automation. My interests span offensive security and cloud defense, with a strong emphasis on researching and building AI-powered cybersecurity tools that improve both attack efficiency and defensive visibility. I actively work on advanced exploitation techniques and developing reliable, AI-assisted red team workflows that mirror real-world threat behavior. Currently, I’m deepening my expertise in advanced Active Directory attacks, AWS cloud security, and applying AI to detection engineering and security analytics. Overall, I enjoy using AI to automate repetitive security tasks so I can focus on what matters most—breaking systems ethically and efficiently 😄
